① 剧本 · AI 编剧

粘贴小说/素材 → 保存 → AI 编剧。配置了本地 LLM（config.yaml 的 llm_base/llm_model）会一键生成剧本草稿； 无 LLM 时输出"Agent 编剧指令"，发给任意 AI Agent（Reasonix / Codex / Claude），由 Agent 把剧本写入 剧本.md。
