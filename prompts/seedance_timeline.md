# Seedance 2.0 时间轴提示词模板（云端/即梦备用）

> 本地 H3 没显卡时可先在线跑通流程；Seedance 2.0 的参考配额：9 图 + 3 视频 + 3 音频。

## 模板

```
{统一风格前缀}，9:16竖屏，{色调}

0-3秒画面：{景别+运镜+场景建立}
3-6秒画面：{镜头推进，主体引入}
6-9秒画面：{情节发展，冲突展现}
9-12秒画面：{高潮时刻，情绪爆发}
12-15秒画面：{结尾落版，氛围延续}

【声音】{配乐风格} + {音效} + {对白}
【参考】@图片1 角色，@图片2 场景...
```

## 示例（水墨武侠）

```
Chinese ink wash painting style mixed with anime cel-shading，9:16竖屏，灰白墨黑色调

0-3秒画面：高空俯拍，沧州草料场雪景，风雪渐起
3-6秒画面：镜头推进，林冲披斗篷立于门前，目光沉静
6-9秒画面：中景，林冲缓缓握紧长枪，动作蓄力
9-12秒画面：特写，枪尖刺出，草料场火光骤起
12-15秒画面：结尾落版，雪夜火光交织，氛围延续

【声音】萧瑟古筝配乐 + 风雪声/火焰声 + 对白：今夜，不走了
【参考】@图片1 林冲定妆照，@图片2 草料场雪景
```

## 集间串联（视频延长）

- 从第 2 集起：上传上一集视频为 `@视频1`
- 提示词开头加：`将@视频1延长15s`
- 转场不自然时显式写："画面渐暗过渡，天色从夜晚转为清晨"

## 运镜关键词速查

| 效果 | 关键词 |
|---|---|
| 推近 | 推镜头 / 缓慢推近 / 急速推进 |
| 拉远 | 拉镜头 / 逐渐拉远 |
| 左右 | 左摇 / 右摇 / 横移 |
| 跟随 | 跟随镜头 / 跟拍 |
| 环绕 | 环绕镜头 / 360度旋转 |
| 升降 | 升镜头 / 降镜头 / 俯冲 |
| 特效 | 希区柯克变焦 / 一镜到底 |
| 手持 | 手持晃动 |

## 限制备忘

- 每集最多 9 图 / 3 视频参考
- 敏感词会整段失败：二分法排查，积累黑名单
- 复杂指令（300+ 字）遵循不稳定：拆短
- 尾帧描述单独记录，供下一集衔接
