## §1 主流工作流调研结论（2026，详见调研报告）

### 1.1 阶段划分共识（Seedance 2.5 / Kling 3.0 / Runway Gen-4 / 开源管线）
```
概念/剧本 → 角色/资产设计（锚点图）→ 分镜脚本（每镜时长/运镜/对白）→ 分镜参考图/首帧
→ 逐镜生成（3-5 变体抽卡）→ 选片（gold take）→ NLE 拼接/调色/字幕/音频 → 审片（QC 门禁）
```
- 开源标杆（ai-shorts-factory / movie-gen / ArcReel）：**所有计划工件持久化 + 评审门禁**；shot_plan 单一参数源，成片由同一张 shot table 驱动（杜绝两处定义漂移）
- 一致性手段：角色=大头照+全身照两张锚点（禁三视图）；同序列同批生成保光线/种子连续；参考锁定 3-5 个受保护细节
- 抽卡：每镜 3-5 变体；草稿 480p/精修 720p；fast/quality 分层；种子记 manifest
- 运镜：每镜一个主运镜；Kling 数值化 azimuth/elevation + 缓入缓出；H3 三段式（类型+幅度+速度）；气闸缓冲（新镜开头保持上镜末构图 ~2s）
- 提示词分层：剧本层禁止整本进 prompt（火山官方警告）；分镜提示词=模板组装器（分镜行+资产引用声明+全局尾禁制），必填=画面/运镜/动作/情绪/音效台词/衔接
- 成片：ffmpeg concat + 全局调色 + 字幕/文字后置；音乐/环境音为合成层；剪映草稿导出兜底
- 修复分层：问题决定修复层（trim 免费 > 配音 > 重帧 > 整镜重拍）；单层重做保留其他层；版本化不覆盖；同一问题两次失败即改剧情
- QC：六维评分（钩子/音画同步/视觉一致/信息密度/情绪节奏/音频融合），<75 触发重做
- AI 工具化形态：Runway MCP 接 Claude/ChatGPT；Higgsfield CLI 由 Claude Code 驱动全流程（人只登录+审片）——与本项目「对话→工具/CLI」方向一致

### 1.2 直接落地到本项目的要点
1. 分镜行=唯一参数源（已定，docs/12）：提示词/抽卡/成片全部从分镜行生成，零重复配置
2. 资产锚点规范：每角色登记大头照+全身照两张（现有资产图即锚点）；资产按 角色锚定/场景定调/运镜参考/节奏氛围 四类注册（现有 C/S/P/R 对应）
3. 分镜提示词=模板组装器（P6 实现）：分镜行内容 + 资产引用声明 + 全局风格 + H3 三段式（缺一不可）+ 参考锁定细节
4. 抽卡参数分层：生成层只留 候选数(3-5)+模式(草稿/精修)；种子记 manifest（现有 candidates 文件即 manifest）
5. 选片=gold take：质检 ok 优先、光线一致/漂移最小者优先（自动选片工具按此规则）
6. 重做分层：单镜重抽保留其他镜（已有 redrawShot）；版本化不覆盖（P5 已有）
7. 修复阶梯入对话：对话说「重做镜3」=整镜重抽；「删镜2对白」=patch；问题决定层

## §2 AI 全操作能力矩阵（核心设计）

原则：**每个"人能做的操作" = 一个 agent 工具**，注册进 manager 工具表；对话意图 → 工具分派 → 执行 → 事件回执（trace/审计）→ SSE 回显。参数不得重复配置：**一律从之前步骤的真理源引用**。

| # | 人操作 | 工具（manager 分支/CLI） | 前置条件 | 参数来源（真理源） |
|---|---|---|---|---|
| T1 | 写/改小说、简报 | aiwrite 分支（novel_from_idea / brief_from_idea / write_novel） | 无 | 对话文本 |
| T2 | 链式编剧（事件/骨架/剧本/资产） | aiwrite 分支（chain） | 小说或想法 | 小说.md+简报.md |
| T3 | 改剧本正文 | patch 分支（脚本块规则）+ 剧本视图人工编辑 | — | 对话 |
| T4 | 资产登记/删除 | **新增** asset 分支（解析资产清单→/api/asset 登记/删除） | 资产清单.md 或对话描述 | 资产清单.md |
| T5 | 资产生图并注入 | **新增** image-gen 分支：外部生图（OpenAI 兼容生图 API 或本地 ComfyUI T2I）→ 存 assets/<类型>/<代号>.png → 注册表更新 | 资产描述（描述=注册表字段） | 资产描述+全局风格 |
| T6 | 拆分镜 | storyboard 分支（llm 优先/解析器） | 剧本.md | 剧本镜头序列 |
| T7 | 改分镜字段（含交换顺序） | patch 分支扩展：镜N｜字段｜值 + **「交换镜X和镜Y」规则** | 分镜存在 | 对话 |
| T8 | 生成/刷新分镜提示词 | **新增** prompt 分支：分镜行+资产+H3 skill → refs/*.prompt.md | 分镜行存在 | 分镜行+资产（自动） |
| T9 | 抽卡（单镜/多镜/重抽） | render 分支 | **分镜提示词已生成（硬前置）** | 分镜行+提示词+config（无重复参数） |
| T10 | 选片（人工/自动） | **新增** select 分支：按质检结果自动选 或 对话指定「选第N镜第M候选」 | 候选存在 | 质检结果/对话 |
| T11 | 成片/重拼/顺序编排 | compose 分支 + **compose-order 工具**（对话：「把镜3放到镜1前面」） | 已选片 | 顺序（默认分镜行序） |
| T12 | 版本回滚 | **新增** restore 分支（doc_versions.restore） | 版本存在 | 对话（回滚到哪版） |
| T13 | 查询状态/看板 | 看板段（build_project_summary，已有） | — | — |
| T14 | 设置（模型/阈值/skill） | **新增** settings 分支（读/写 config.local.json） | — | 对话 |
| T15 | 外部 agent 委派 | 外派 tool 事件（已有：CLI/ACP） | 无法本地解析时 | 上下文摘要 |

**工具注册与分派**：agent_manager 维护 TOOL 表（tool_id → {意图关键词, 前置校验, 执行函数, 事件文案}）；意图解析 v1 规则式 + 未命中 → 外派。事件回执统一走 _ev（kind=tool/subtask/patch）。

**抽卡参数引用链（用户核心要求落地）**：
```
分镜行（时长/景别/运镜/角色/场景）─┐
资产库（名称/图/描述）────────────┼→ 分镜提示词（refs/*.prompt.md，T8 生成）→ 抽卡（T9）
全局风格（config project.style_prefix）┘  参数：仅 候选数+模式；其余全部引用，无重复配置
```

## §3 执行计划

### P6a 后端能力（先行，契约先行）
1. manager 新增工具分支（全走 _ev 回执）：asset 登记/删除、image-gen（外部生图 API 抽象：OpenAI 兼容生图端点，config `image:` 段，产物存 assets/<类型>/<代号>.png + 注册表更新 + rev）、prompt 分支（分镜提示词生成/刷新：分镜行+资产+H3 skill → refs/*.prompt.md）、select 分支（自动选 gold take：质检 ok 优先/光线一致；或对话指定「选第N镜第M候选」）、restore 分支（doc_versions）、compose-order 工具（「把镜3放到镜1前面」）、settings 分支（config.local.json agent 段读写）
2. render 硬前置：refs/*.prompt.md 缺失 → 拒绝（/api/render 与 manager render 分支同规则，提示「先生成分镜提示词」）
3. /api/compose 接受 order + GET/PUT /api/compose-order（E{n}/compose.order.json）
4. /api/canvas selected 幽灵过滤（仅现存分镜行）
5. patch 分支扩展：交换镜序规则（「交换镜X和镜Y」）、资产增删规则
6. 抽卡参数收敛：生成层仅 候选数+模式；时长/分辨率由分镜行+config 派生
7. pytest + 冒烟（18997）

### P6b 前端重构（按 docs/12 §4 变更清单）
1. ScriptView/ScriptPanel：删一键/分步 AI 按钮（AI 唯一入口左栏）
2. ShotFields：角色/场景=资产下拉（C/S/P/R 分组+名称+自由输入兜底）
3. Inspector：分镜提示词面板（改名、生成/刷新、空则禁抽卡）→ 候选墙（候选数+模式；点击播放试看 overlay+显式选中确认）→ A/B
4. ShotCard：只读摘要卡（去内嵌编辑；镜号/时长/景别/运镜/角色名/场景名/灯光/对白摘要+资产图缩略+徽标）
5. ComposeView：成片编排台（拖拽重排→PUT compose-order；拼接按序；预览）
6. CandidateWall：抽卡按钮前置禁用；参考图=自动关联+手动覆盖
7. build（前端冒烟 18996 页面 200）

### 验收（对齐用户 5 点 + Q14-19）
- 剧本视图零 AI 按钮；左栏对话可完成 T1-T15 全部操作（至少 T1-T12 实测）
- 抽卡阶段零重复配置；提示词未生成不可抽卡
- 候选可试看播放；网格卡只读；成片可拖拽排序
- 分镜/成片数据同源一致；幽灵数据清理
- pytest 全绿 + build + 18999 冒烟 + 真实对话链路（含一句"生图注入资产"冒烟，若生图 API 未配则跳过并注明）
