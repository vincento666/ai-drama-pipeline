# 07 · 自动化编排（scripts/pipeline.py）

编排层把「业界方法论」固化成一条命令链：**初始化 → 剧本 → 资产 → 分镜提示词 → 抽卡 → 校验 → 拼接**。
所有脚本只用 Python 3 标准库，无第三方依赖，在本机（甚至无 GPU 的机器）可跑。

## 1. 命令总览

```bash
# 初始化一个项目（建目录结构 + 分镜骨架）
python3 scripts/pipeline.py init my-drama --episodes 5

# 干跑第 1 集：打印每一步要做什么、产出什么，不真正执行
python3 scripts/pipeline.py run my-drama --episode 1 --dry-run

# 正式跑第 1 集（交互式，每步等你确认/挑选）
python3 scripts/pipeline.py run my-drama --episode 1

# 只做某一段
python3 scripts/pipeline.py storyboard my-drama --episode 1     # 分镜→提示词
python3 scripts/pipeline.py verify my-drama --episode 1         # 校验素材是否齐全
python3 scripts/pipeline.py compose my-drama --episode 1        # ffmpeg 拼接
```

## 2. 项目目录约定（init 自动创建）

```
output/my-drama/
├── 剧本.md                  # 四幕结构剧本（AI 起草，人审）
├── 素材清单.md               # C/S/P 资产清单（asset_manager 生成）
├── E01/
│   ├── 分镜.md              # 8-12 格分镜表
│   ├── prompts_h3.md        # 每镜的 H3 三段式提示词（gen_storyboard 生成）
│   ├── shots/               # 抽卡出的视频（人下载/脚本复制进来）
│   └── 成片.mp4             # compose 输出
└── ...
```

## 3. pipeline 流程（每步对应方法论）

| 步骤 | 脚本动作 | 人做什么 | 方法论映射 |
|---|---|---|---|
| 1. init | 建目录、生成剧本骨架 | 填选题/改写剧本 | 四幕剧本 |
| 2. assets | 调用 asset_manager 检查 C/S/P 齐全 | 生成/挑选定妆照、场景图 | 资产先行 |
| 3. storyboard | 解析分镜表 → 输出每镜 H3 提示词 | 编辑分镜表（景别/机位/时长） | 分镜设计 |
| 4. generate | 打印提示词 + ComfyUI 工作流指引 | 去 h3-studio/ComfyUI 抽卡，把中选片拷入 shots/ | 批量抽卡-人工挑选 |
| 5. verify | 校验 shots/ 每镜至少 1 个视频、时长匹配 | 补缺 | 质检门 |
| 6. compose | ffmpeg 按分镜顺序拼接 → 成片.mp4 | 之后进剪映加字幕/调色 | 剪辑成片 |

## 4. dry-run 示例

```bash
python3 scripts/pipeline.py run demo --episode 1 --dry-run
```

输出类似：
```
[DRY-RUN] 步骤 1/6 剧本     → 检查 output/demo/剧本.md 存在
[DRY-RUN] 步骤 2/6 资产     → 需要: C01,C02,S01,S02 (当前: 0)
[DRY-RUN] 步骤 3/6 分镜     → 需要: output/demo/E01/分镜.md 存在
[DRY-RUN] 步骤 4/6 生成     → 会提示去 http://127.0.0.1:8188 抽卡并拷入 shots/
[DRY-RUN] 步骤 5/6 校验     → 检查 shots/ 视频数量 >= 分镜数
[DRY-RUN] 步骤 6/6 拼接     → ffmpeg 拼接为 output/demo/E01/成片.mp4
```

## 5. 设计原则

- **人不被脚本绑架**：每步可跳过（`--skip storyboard`），生成步骤永远留给人工挑选
- **可追溯**：分镜表、提示词、素材清单都是 Markdown/CSV，进 git；`verify` 对照素材清单检查
- **零依赖**：标准库搞定，任何机器 clone 即用
- **配置驱动**：ComfyUI 地址、分辨率、模型名都在 `config.yaml`
