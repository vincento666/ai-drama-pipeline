# 09 · 前端工作流设计（剧本分段 → 分镜管理）

> 版本：v1 设计稿 · 2026-08-10
> 范围（首版）：**剧本分段 → 分镜管理**（抽卡画廊、拼接剪辑为 v2/v3 路线图）
> 参考对象：即梦（Seedance）/ 可灵 / 剪映的剧本-分镜-成片工作流
> 现状：本项目编排层为 CLI（`pipeline.py init/storyboard/render/verify/compose`），
> 数据源是 `output/<项目>/剧本.md` 与 `output/<项目>/E<n>/分镜.md`（markdown 表），无 UI。

---

## 1. 设计目标

给"机器批量生成、人做判断"的流水线一个**以剧本为核心的分镜管理界面**：

1. **剧本分段**：把一段剧本（文字）切成"幕 → 集 → 镜头段落"的树，人可合并/拆分/微调；
2. **分镜管理**：每个镜头段落对应一行分镜（景别/运镜/角色/场景/对白/音效），
   与现有 `分镜.md` 表**双向同步**——前端改完，CLI 照常用；
3. **为 v2 预留**：段落 → 提示词预览（`gen_h3`）与"抽卡画廊"入口，本版只做占位。

不重复造生成引擎（ComfyUI 8188 已提供），也不替代剪辑软件（剪映草稿导出在路线图）。

---

## 2. 主流产品流程参考（为什么这样分段）

| 产品 | 剧本处理方式 | 可借鉴点 |
|---|---|---|
| 即梦（Seedance） | 粘贴剧本 → 自动按情节切"场景段" → 每段一键生成片段 | **自动分段 + 人工可调**的粒度 |
| 可灵 | 剧本 → 分镜脚本（镜头表）→ 每镜多候选 | 镜头表列模型（景别/运镜/时长） |
| 剪映（图文成片） | 段落 → 素材匹配 → 时间线 | 段落即时间线最小单元 |

**共识流程**：`剧本文本 → 情节分段（幕/场）→ 每段拆镜头（分镜行）→ 逐镜抽卡挑选 → 时间线拼接`。
本设计沿用此流程，但把"分段"做成**半自动**：脚本按剧本标题/空行给初稿分段，人拍板。

---

## 3. 核心数据模型（与现有脚本打通）

```
项目(project)
└─ 剧本.md          # 四幕结构文本（现有 SCRIPT_TEMPLATE）
└─ E01/
   ├─ 分镜.md       # markdown 表：镜号|景别|运镜|时长|角色|场景|灯光|对白/音效|备注
   └─ shots/        # 抽卡产物（v2）
```

前端不另造数据源，**读写同一个 分镜.md**：
- 解析：复用 `gen_storyboard.parse_markdown_table`（已支持中英列名别名）；
- 写回：按同样表头序列化，保证 CLI `verify/compose/render` 零改动继续工作；
- 同步策略：前端保存时全量重写该文件（单集粒度，无并发冲突问题）。

分段树（前端内存模型）：
```
剧本
└─ 幕（四幕：起/承/转/合）          ← 来自 剧本.md 的 "## 第X幕" 标题
   └─ 集（E01, E02…）              ← 项目已有
      └─ 镜头段落（分镜行）          ← 分镜.md 的每一行
```

## 4. 用户旅程（工作流程）

### 4.1 新建/打开项目
- 项目列表 = `output/` 下已有目录；新建时调 `pipeline.py init`。
- 打开后进入"剧本分段"页。

### 4.2 剧本分段（本版核心）
1. **导入剧本**：粘贴文本 / 选择已有 `剧本.md`；
2. **自动分段**：按 `## 第X幕` 标题与空行/句号切出候选段落，每段给"情节摘要"（首句）；
3. **人工调整**：合并相邻段（拖动/按钮）、拆分长段（光标处切分）、改段名；
4. **段落 → 分镜行**：每段默认生成一行分镜（景别=中景、运镜=static、时长=5s），
   人工在分镜表补角色/场景/对白；
5. **保存**：写回 `E01/分镜.md`（列不变，行数 = 段落数）。

### 4.3 分镜管理（本版核心）
- 表格化编辑：与 `分镜.md` 完全一致的列，下拉框提供词表（景别/运镜来自
  `gen_storyboard.CAMERA_VOCAB / FRAME_VOCAB`）；
- 行内校验：角色编号须 `^[CSPR]\d{2}$` 且已登记（同 `asset_manager`）；
- 每行右侧"提示词预览"：调 `gen_h3` 单镜版（`shot_h3`），只读展示；
- 操作：增行/删行/上下移/复制行/清空重置。

### 4.4 出口（占位 → v2/v3）
- "生成候选"按钮 → 调 `pipeline.py render --only <镜号>`（v2 实现画廊）；
- "校验/拼接"按钮 → `verify` / `compose`（v3 时间线预览）。

## 5. 界面结构（单页三栏 + 顶栏）

```
┌────────────────────────────────────────────────────────────────────────┐
│ 顶栏: [项目▾] [E01▾] | 分段视图 | 分镜表 | (v2:抽卡画廊 | v3:时间线)  [保存] │
├──────────────┬────────────────────────────────────┬────────────────────┤
│ 剧本分段树     │  分镜表（可编辑）                    │ 分镜详情 / 提示词   │
│              │                                    │                    │
│ 📖 剧本        │ 镜号|景别|运镜|时长|角色|场景|对白   │  ─ 镜 3 ─          │
│ ├─ 第一幕·起   │  1 |wide|push in| 5| 无 |S01|…    │ 景别: 近景 ▾       │
│ │  ├ E01      │  2 |med |static | 5|C01|S01|…    │ 运镜: 推近 ▾       │
│ │  │ ├ 段1     │  3 |close|static | 5|C01|S01|…  │ 角色: C01(已登记✓)  │
│ │  │ ├ 段2     │  …                              │ 对白: 这里发生了什么 │
│ │  │ └ 段3     │  [＋行][合并][拆分][↑][↓][🗑]     │ ── 提示词预览 ──    │
│ ├─ 第二幕·承   │                                  │ integrated_…      │
│ └─ …          │                                  │ overall_sound…    │
│              │                                  │ [生成候选(v2)]      │
└──────────────┴────────────────────────────────────┴────────────────────┘
```

要点：
- **左栏分段树**：幕/集/段落三级，点段落定位到分镜行；段落在树内拖拽排序；
- **中栏分镜表**：词表下拉 + 行操作；表头与 `分镜.md` 严格一致，所见即所得；
- **右栏详情**：选中行的字段编辑 + 实时提示词预览（只读，来源 `shot_h3`）；
- 顶部标签预留 v2（抽卡画廊）/ v3（时间线）占位，本版置灰。

## 6. 技术选型建议（实施时定）

| 方案 | 说明 | 取舍 |
|---|---|---|
| A. 纯静态单页（推荐起步） | HTML+JS，本地 `file://` 或 `python -m http.server`；文件读写用"打开/保存"对话框或小型本地桥 | 零依赖，但自动读写 分镜.md 需要文件桥 |
| B. 极简本地桥 | 一个 `server.py`（标准库 http.server）暴露 `GET/PUT 分镜.md` + `POST render` 代理 | 约 100 行，仍是零 pip 依赖，推荐 |
| C. Flask/FastAPI | 功能全（拖拽上传、WebSocket 进度），需 pip install | 依赖安装，留给 v2 画廊 |

建议首版走 **B**：脚本层（`pipeline.py` / `gen_storyboard.py` / `asset_manager.py`）作为后端
逻辑全部复用，前端只做视图与交互，不复制任何业务逻辑。

## 6.5 创作向导（v1.1 已实现，借鉴 Toonflow 引导式流程）

- 顶部 **7 步步骤条**：剧本 → 分段 → 分镜 → 资产 → 抽卡 → 选片 → 拼接；
  每步显示完成状态（✓/未做），点击导航到对应工作区；
- **第 1 步剧本面板（AI 编剧）**：粘贴小说/素材 → 保存为 `小说.md` → AI 编剧：
  - 配置了本地 LLM（config.yaml `llm_base`/`llm_model`）→ 一键生成四幕剧本草稿写 `剧本.md`；
  - 无 LLM → 输出"Agent 编剧指令"（含小说 + 四幕模板 + 交付说明），
    复制给任意 AI Agent（Reasonix/Codex/Claude）执行——契合"Agent 是导演"定位；
- 状态数据源：`GET /api/wizard/<项目>`（7 步 done/count/hint）。

## 8. 验收标准（v1）

- [ ] 打开已有项目：`output/smoke` 的 `分镜.md` 能原样载入表格；
- [ ] 自动分段：按幕标题把 `剧本.md` 切成树，段落数 = 分镜行数；
- [ ] 人工调整：合并/拆分/排序后保存，`分镜.md` 行数与内容一致；
- [ ] 校验提示：未登记角色编号标红（与 `asset_manager check` 同规则）；
- [ ] 提示词预览与 `gen_h3` 单镜输出逐字符一致；
- [ ] 保存后 `pipeline.py verify smoke --episode 1` 行为不回归。
