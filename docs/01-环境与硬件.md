# 01 · 环境与硬件

## 1. 角色分工：本机 vs 生成引擎

本骨架把系统拆成两层，可以跑在同一台机器，也可以分开：

| 层 | 跑什么 | 硬件需求 | 是否必须 |
|---|---|---|---|
| 编排层（本机） | `scripts/*.py`、文档、提示词模板 | 任何机器（Python 3.8+） | 是 |
| 生成层 | ComfyUI + H3 权重 + 本地 LLM | 独立显卡（见下） | 是 |

生成层通过 `config.yaml` 里的 `comfyui.base_url` 访问，**本机脚本不需要 GPU**。
如果本机没显卡，就在云 GPU 上装生成层，把 base_url 指向它（注意安全：建议加 ComfyUI 的 `--listen` + 防火墙/内网穿透，勿裸奔公网）。

## 2. 显存需求速查

H3 是 33.1B 全能 Transformer + Qwen3-VL-32B 文本编码器。社区实测（RTX 5080 16GB）：

| 配置 | 显存占用 | 出片速度参考（864×480, 124帧, 20步） | 结论 |
|---|---|---|---|
| NVFP4 量化 | ~15.5 GB | 首次 ~150s，热缓存 ~100s | 16GB 卡主流选择 |
| NVFP4 + 12B LLM(Q8) 同驻 | ~30 GB | — | 必须错峰加载（h3-studio 自动做 VRAM handoff） |
| 全量 FP16/FP8 | 48~70 GB+ | — | 24GB 卡吃不下，需要 A100/H100 或双卡 |
| GGUF 更深量化（INT4 等） | 6~10 GB | 显著变慢 | 8GB 卡（如 3060 12GB 也可试） |

**结论**：16GB 显存是甜点（RTX 4080 / 5080 / 4090 laptop 等）。8GB 可以跑但慢。无显卡/Apple Silicon 用户建议直接云 GPU。

## 3. 推荐部署方案（按预算）

1. **白嫖验证**：用官方在线 Hailuo（海螺 3.0）跑通流程，本地只装编排层——先把方法跑顺，再花钱上本地。
2. **单机 16GB**：ComfyUI + H3(NVFP4) + Ollama 跑 12B LLM，错峰加载。
3. **云 GPU 按小时**：AutoDL（国内）/ RunPod / 火山引擎 GPU 实例租 24GB 卡（约 ¥2-5/小时），装生成层，本机连远程 ComfyUI。适合量产期集中渲染。
4. **混合**：人物一致性/首尾帧等关键镜头用本地 H3 精调，普通镜头用在线 API（Seedance/即梦）批量抽卡。

## 4. 前置软件清单（生成引擎侧）

- Python 3.10+（ComfyUI 官方要求；macOS 系统 Python 3.9 不够，用 uv/miniconda 装 3.10+）
- git
- NVIDIA 驱动 + CUDA（Linux 用 PyTorch cu121+；Windows 用官方 CUDA 安装）
- ffmpeg（剪辑拼接用，`brew install ffmpeg` / `apt install ffmpeg` / winget）
- 磁盘空间：H3 权重合计约 30~60GB（取决于量化），预留 100GB 保险

## 5. 第一步：确认本机有没有 Python 3.10+

```bash
python3 --version   # 若 < 3.10，见下方指引
which python3
```

macOS 用户建议：`brew install python@3.12` 或 `brew install uv && uv python install 3.12`。
生成层机器（Linux/Windows）同理装 3.10+。

> 本骨架的 `scripts/` 用 Python 3.8+ 兼容语法，但 ComfyUI 本身要求 3.10+。
