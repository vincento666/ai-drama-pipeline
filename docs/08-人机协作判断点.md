# 08 · 人机协作判断点（人的工作清单）

**原则：机器批量干活，人只做判断与组织。** 下面是每条流水线上**必须由人拍板**的 9 个决策点，以及判断标准。把它打印出来贴在工位上即可。

## 每个环节的人工决策点

| # | 环节 | 人判断什么 | 判断标准 / 检查清单 |
|---|---|---|---|
| 1 | 选题/IP | 这个题材适不适合 AI 短剧？ | 2-3 分钟/集节奏；角色 ≤4 个、场景 ≤6 个（直接决定成本）；受众画像清晰；版权/敏感词风险 |
| 2 | 剧本 | AI 写的四幕剧本爽点/节奏是否成立 | 每 3-5 秒一个信息点；结尾钩子（追下集）；AI 只做格式化，**核心梗人工把关** |
| 3 | 素材清单 | 定妆照/场景图是否达标 | 同角色多角度一致（发型/瞳色/色值统一）；风格前缀统一；**每角色一张图只锁一个角色** |
| 4 | 分镜 | 每镜景别/机位/时长是否表达情绪 | 8-12 格/集；对白戏给近景+特写；动作戏给运动镜头；**双人同框注意手部** |
| 5 | 提示词 | 三段式/时间轴是否写全 | 封闭镜头词汇；对白带 `<d>`；音效/配乐分字段；排除句（无字幕/无 logo） |
| 6 | 抽卡 | 同一镜头 3-5 个变体里挑哪条 | 人脸细节清晰（无"旋涡糊"）；口型对齐；音画同步；**角色像不像**（对照定妆照） |
| 7 | 质检 | 这集能不能过 | 时长符合分镜；无残影/穿帮；语言发音正确；字幕阶段补 |
| 8 | 剪辑 | 粗剪/转场/情绪节奏 | 音效营造 → 风格调色 → 字幕包装；前 3 秒抓人 |
| 9 | 发布 | 平台/矩阵/数据 | 平台分账规则；是否矩阵运营；敏感词二次核查 |

## 哪些事**不要**让人做（机器做）

- 逐字逐句写分镜描述 → `gen_storyboard.py` + 模板生成
- 逐镜头重试抽卡 → ComfyUI Queue 批量 + seed 固定
- 素材清单/编号登记 → `asset_manager.py`
- 拼接/格式转换 → `compose.py` + ffmpeg

## 哪些事**必须**人做（机器做不了/做不好）

- 剧情爽点、笑点、反转设计（一线导演共识：AI 剧本帮助有限）
- 敏感词/版权/肖像权终审（AI 生成真人脸易撞明星）
- 品牌调性与运营策略
- "这一条抽卡结果能不能用"的审美判断

## 单集时间预算（团队实测参考，1 人 + 本地 16GB 卡）

| 环节 | 耗时 | 说明 |
|---|---|---|
| 选题+剧本 | 0.5-1h | AI 起草，人改 |
| 资产准备 | 1-2h | 首次建库慢，之后复用 |
| 分镜+提示词 | 0.5-1h | 模板化后很快 |
| 抽卡生成 | 1-3h | 每镜 3-5 变体，可睡觉挂机 |
| 挑选+剪辑 | 1-2h | 剪映粗剪+字幕 |
| **合计** | **4-9h/集** | 批量并行后接近 1 天 1 集 |

> 商业平台（星火动漫等）单部成本从 40 多万降至 20 多万、月产一部，本地方案+人工把关的产量约为其 1/3-1/2，但**完全自有可控、零 API 费用（仅电费/云 GPU 时租）**。
