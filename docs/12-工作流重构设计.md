# 工作流重构设计 v2（单一真理源 · 每步唯一操作）

> 背景：用户验收反馈 5 类问题——①剧本分步按钮多余 ②成片轨无编排意义 ③成片有数据而分镜空（数据源发散）④分镜环节大量重复配置（角色手填/参考图手动/抽卡参数重复/网格卡片重复/抽卡无提示词前置/候选不可试看）⑤全流程聚焦性与唯一性审查。
> 原则（承接 docs/11）：任务优先信息架构 + 渐进式披露 + 对象-动作-反馈 + **单一真理源** + **每步唯一操作**（不同视图切换除外）。

## 0. 现状问题 → 方案映射

| # | 用户问题 | 根因 | 方案 |
|---|---|---|---|
| 1 | 剧本分步/一键 AI 编剧按钮多余 | AI 入口重复（左栏对话 vs 面板按钮） | 删 ScriptPanel 全部 AI 按钮，AI 唯一入口=左栏；剧本视图=文档编辑+简报+版本历史 |
| 2 | 成片轨无意义/不能拖拽/拼接按钮没用 | 成片轨只读展示，无编排能力 | 成片视图升级=**成片编排台**：拖拽重排已选片段，拼接按轨顺序（后端 compose 支持顺序） |
| 3 | 成片有数据而分镜空 | 数据源发散：ComposeTrack 直读 /api/storyboard，BoardCanvas 读 /api/canvas，可不一致；selected 含幽灵文件 | 统一数据源（画布聚合包）+ selected 只计入现存分镜行（幽灵清理） |
| 4a | 角色/场景要手填 | ShotFields 自由输入，无资产联动 | 角色/场景=**资产下拉**（代号选择器，显示名称+图）；灯光/对白自由文本 |
| 4b | 抽卡后不能播放试看 | 候选墙 video 无 controls，点击=选中 | 候选视频点击**播放试看**（大图播放/controls），选中改为显式按钮 |
| 4c | 还要手动配参考图 | ShotRefPanel 手动生成，与资产库脱节 | 参考图**自动关联**（该镜角色/场景资产图），手动覆盖仅作补充；面板改名「分镜提示词」 |
| 4d | 网格卡片与右侧重复 | ShotCard 内嵌 ShotFields 编辑，Inspector 也编辑 | 网格卡片**只读摘要化**；编辑唯一入口=Inspector |
| 4e | 没提示词就能抽卡 | /api/render 内部构造提示词，无前置产物 | **分镜提示词前置**：抽卡前必须已生成（refs/*.prompt.md 非空），提示词面板=生成/刷新入口 |
| 4f | 抽卡参数与分镜卡重复（时长等） | 抽卡面板暴露与分镜行重复的参数 | 抽卡参数收敛为：**候选数 + quick/std**；时长/分辨率由分镜行+config 派生（真理=分镜行） |
| 5 | 全流程聚焦性 | 各环节重复操作 | 见 §3 每步唯一操作表 |

## 1. 单一真理源（数据架构）

| 数据 | 真理源 | 消费方 | 说明 |
|---|---|---|---|
| 创作意图 | 创作简报.md | 链式编剧 | 对话自然产出 |
| 故事素材 | 小说.md | 链式编剧 | 对话从零生成或粘贴 |
| 故事结构 | 小说事件.md / 故事骨架.md / 剧本.md | 分镜生成 | 链式产物，可人工改（剧本视图编辑） |
| **分镜** | **E{n}/分镜.md 行** | 画布/Inspector/成片轨/抽卡/提示词 | 镜号/景别/运镜/时长/角色(代号)/场景(代号)/灯光/对白/备注 |
| 资产 | assets/ 注册表 | 分镜显示/参考图/提示词 | 代号 C/S/P+两位 → 名称/图/描述（分镜行只存代号） |
| 分镜提示词 | E{n}/refs/*.prompt.md | 抽卡 | **抽卡前置产物**（分镜行+资产+H3 skill 生成） |
| 候选/选片 | E{n}/shots/.candidates/ + shots/ | 成片轨/质检 | selected 只计入现存分镜行 |
| 成片顺序 | 分镜行顺序（默认）或 成片轨拖拽顺序（覆盖） | 拼接 | 见 §2 决策 D1 |
| 版本 | profile/versions/ | 回滚/撤销 | P5 已建 |

**一致性规则**（后端 /api/canvas 聚合包内实现）：
- `selected` 过滤：仅保留存在于当前分镜行的 shot_XX.mp4（幽灵清理）
- ComposeTrack 与 BoardCanvas 同源（画布聚合包），消除发散

## 2. 待拍板决策（已给推荐）

- **D1 成片顺序**：默认=分镜行顺序；成片编排台支持拖拽重排（顺序写入 E{n}/compose.order.json），拼接按此顺序（后端 /api/compose 接受 order）。⬅ 推荐
- **D2 网格模式**：保留（幕树结构化查看）但卡片只读摘要化（去内嵌编辑），编辑唯一在 Inspector。⬅ 推荐（也可删除网格模式只留时间轴，布局更简）
- **D3 角色/场景输入**：资产下拉（含"自由输入"选项兜底非注册资产）。⬅ 推荐
- **D4 抽卡硬前置**：分镜提示词未生成 → 抽卡按钮禁用（提示「先生成分镜提示词」）。⬅ 推荐
- **D5 参考图**：自动关联（该镜角色/场景资产图，可多选覆盖）；抽卡请求默认带关联资产。⬅ 推荐

## 3. 新工作流 · 每步唯一操作

```
① 剧本       左栏对话驱动（写/改/从零编剧）或 剧本视图直接编辑剧本.md
             ——视图提供：简报卡片(折叠) + 剧本.md 编辑器 + 版本历史/撤销
             ——唯一操作：编辑剧本正文；AI 入口=左栏
② 美术·资产   资产视图：登记/上传/删除/风格（现状保留）
             ——唯一操作：资产增删改
③ 分镜       视图头「从剧本生成分镜」按钮（或左栏对话"拆分镜"）
             ——卡片：只读摘要（镜号/时长/景别/运镜/角色名/场景名/灯光/对白 + 资产参考图缩略 + 已选/候选状态点）
             ——Inspector（唯一编辑点）：字段编辑（角色/场景=资产下拉）+ 分镜提示词（生成/刷新）+ 抽卡（前置=提示词已生成；参数=候选数+模式）+ 候选墙（播放试看/质检/A-B/选片）
④ 成片       成片编排台：已选片段轨（拖拽重排，可播放）+ 拼接成片（按轨顺序）+ 成片预览
             ——唯一操作：编排顺序 + 重拼
⑤ 全局       版本回滚（各文档）｜ 执行记录/审计（右栏）｜ 设置（三子菜单）
```

**已删除的重复入口**：ScriptPanel 一键/分步 AI 编剧按钮、ShotCard 内嵌字段编辑、抽卡面板的时长/分辨率参数、参考图手动生成（改为自动关联+提示词前置面板）。

## 4. 前端变更清单（派 kimi 实施）

| 组件 | 变更 |
|---|---|
| ScriptView / ScriptPanel | 删 runAll/run 分步按钮区；保留 小说 textarea + 产物预览 tabs + diff 高亮 + 版本历史；文案改「AI 生成请在左侧对话说；此处直接编辑」 |
| ShotCard（网格） | 只读摘要卡：镜号/景别/运镜/时长/角色名/场景名/灯光/对白摘要 + 资产参考图缩略 + 已选/候选徽标；去 ShotFields 内嵌 |
| ShotFields | 角色/场景改资产下拉（C/S/P/R 分组，显示 代号+名称，含自由输入兜底）；时长/景别/运镜/灯光/对白不变 |
| Inspector / ShotInspector | 面板顺序：字段编辑 → **分镜提示词**（改名，生成/刷新/预览，提示词为空时抽卡禁用）→ 候选墙（候选数+模式；候选点击=播放试看，选中=按钮确认）→ A/B → 提示词预览合并进分镜提示词面板 |
| CandidateWall | 抽卡按钮 disabled 条件=提示词未生成；候选点击播放试看（大图 overlay）；参考图下拉改为「自动（镜内资产）+ 手动覆盖」 |
| ShotRefPanel | 改名「分镜提示词」（ShotPromptPanel），删除独立出图概念，展示 refs/*.prompt.md |
| ComposeTrack → ComposeView | 成片编排台：可拖拽排序（vuedraggable 或原生 DnD）、顺序落盘、拼接按顺序、预览 |
| BoardCanvas | 数据源保持 /api/canvas（聚合包已含一致性）；时间轴卡 ref-image 显示资产自动关联图 |
| 右栏/StageNav | 不变 |

## 6. 数据残留与一致性（用户问题 3）

- 现状各项目数据为真实冒烟产物（demo/smoke/smoke_i2va 均有分镜+shots+成片），非 mock
- 修复发散：ComposeTrack 与 BoardCanvas 同源后，"分镜空/成片有"不会再出现
- 新增一致性守卫：selected 幽灵清理（分镜行删除后对应 selected 不计入）
- 可选：提供「清理残留候选/成片」按钮（右栏或成片视图，渐进式披露）——D6 待拍板

## 7. 验收清单（重构后）

1. 剧本视图无任何 AI 按钮；左栏对话可完成全部 AI 操作
2. 分镜字段角色/场景从资产下拉选，显示名称，无需手填代号
3. 分镜提示词未生成时抽卡按钮禁用；生成后可抽卡
4. 候选可点击播放试看；选中为显式确认
5. 网格卡片只读摘要；编辑唯一在 Inspector
6. 成片编排台可拖拽重排并顺序拼接；重拼后成片更新
7. 分镜视图与成片轨数据同源一致（删一行分镜 → 成片轨同步少一段）
8. 全流程每步唯一操作（对照 §3）
9. pytest 全绿 + build 通过 + 18999 冒烟
