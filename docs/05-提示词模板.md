# 05 · 提示词模板（H3 三段式 + Seedance 时间轴 + 角色圣经）

模板文件在 `prompts/`，可直接复制使用。`gen_storyboard.py` 能按分镜自动生成 H3 三段式（见 `07-自动化编排.md`）。

## 1. H3 三段式 schema（本地 ComfyUI 必用格式）

H3 不吃自由文本，ComfyUI 本地没有改写器。标准格式是**三个标签字段，空行分隔，按序排列**：

```
integrated_multimodal_description: [Shot 1] Live-action, cinematic, a medium-wide
shot frames a baker opening the shutters of a small street bakery before sunrise.
The camera pushes in with small amplitude at slow speed as the middle-aged baker
with a calm, slightly raspy voice (S1) places a fresh loaf on the wooden counter
and says: <d>[English] First batch of the morning.</d>

overall_soundscape: Wooden shutters scrape open over a quiet street as trays clink
softly inside the bakery. The doorbell rings once, followed by light footsteps.

non_diegetic_music: A soft acoustic-guitar pattern at a moderate tempo, joined by
sparse upright-bass notes and a gentle fade at the end.
```

规则：
- `integrated_multimodal_description`：逐镜头描述。镜头语法用**封闭词汇表**（见下）；对白用 `<d>[语言] 台词</d>`；说话人标 `(S1)`；第一个镜头之后每个镜头都要带时间戳（如 `[Shot 2 · 00:00:05]`）
- `overall_soundscape`：环境音/拟音（脚步声、开门声、雨声）
- `non_diegetic_music`：配乐（风格、节奏、情绪、结尾淡出）
- 可加排除句在描述末尾：`No text, subtitles, logos or watermarks of any kind.`
- 上限约 7000 字符；**无 negative prompt、无 guidance_scale**（guidance-distilled 单遍前向）

### 封闭镜头词汇表（抄 h3-studio / MiniMax 官方指南）

景别：extreme wide / wide / medium-wide / medium / medium close-up / close-up / extreme close-up
机位/运动：static / push in / pull back / pan left/right / tilt up/down / tracking / crane up/down / handheld / orbit
光线：golden hour / overcast / neon / candlelight / moonlight / hard / soft diffused
时长标记：`[Shot 2 · 00:00:05]`（5 秒处开始）

## 2. Seedance 2.0 时间轴格式（云端备用，另见 prompts/seedance_timeline.md）

```
水墨武侠风格，9:16竖屏，灰白墨黑色调

0-3秒画面：高空俯拍，场景建立
3-6秒画面：镜头推进，主体引入
...
12-15秒画面：结尾落版，氛围延续

【声音】配乐风格 + 音效 + 对白
【参考】@图片1 角色，@图片2 场景
```

集间串联用视频延长：上传上一集视频为 `@视频1`，提示词开头写「将@视频1延长15s」。

## 3. 角色圣经模板（assets/bible/C01_XXX.md）

见 `prompts/character_bible.md`，每个角色一份。要点：
- 固定外貌特征 + 十六进制色值（颜色一致性）
- 道具绑定（"永远手持长枪"）
- 声音设定（"低沉略带沙哑 (S1)"）
- 禁忌清单（"绝无眼镜/纹身"）→ 直接转成排除句

## 4. 分镜板模板（每集 8-12 格）

见 `prompts/storyboard.md`。每格固定字段：

```
| 镜号 | 景别 | 机位运动 | 时长 | 角色 | 场景 | 灯光 | 对白/音效 | 备注(情绪/转场) |
```

分镜文件的解析与提示词生成由 `gen_storyboard.py` 完成（支持 Markdown 表格 / 简易 CSV）。

## 5. 生产铁律（社区蒸馏，直接抄进你的 SOP）

1. 时长分段计算（H3 单段 ≤15s；长镜头靠延长续接）
2. 双人同框锁手部（"两人的手保持静止"写入描述）
3. 对白时间轴对齐（口型：台词放 `(S1)` + `<d>` 标记）
4. 视听语言优先（先景别/机位/光线，后形容词）
5. "提示词即视觉语言"，去 AI 感（少用 "stunning/highly detailed"，多用电影术语）
6. 敏感词规避（平台敏感词可能导致整段失败，积累黑名单）
