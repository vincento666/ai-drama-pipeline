# 04 · 资产库管理（人物一致性 & 场景连续性的地基）

业界共识：**一致性不是靠提示词"祈祷"，是靠资产库强约束**。商业平台（BigBanana「6 层身份锚点」、Kino「双主体资产库」）都是这个思路的开源可替代版。

## 1. 编号规范（沿用 Seedance2-Storyboard-Generator 社区标准）

| 前缀 | 含义 | 编号 | 示例 |
|---|---|---|---|
| `C` | 角色（多角度） | C01-C99 | `C01 林冲·正面全身` |
| `S` | 场景/地点 | S01-S99 | `S01 沧州草料场·雪景` |
| `P` | 道具/物品 | P01-P99 | `P01 长枪` |
| `R` | 风格/参考锚点 | R01-R99 | `R01 水墨武侠风格参考图` |

**命名规则**：`{前缀}{两位序号}_{描述}.png`，例如 `C01_林冲_正面全身.png`。
**单素材一职责**：一张参考图只锁定一个角色或一个场景，绝不混入多主体（H3 参考配额 9图+3视频+3音频，混图会互相污染）。

## 2. 目录结构（本骨架已建好）

```
assets/
├── characters/   C 开头角色定妆照（每角色 3-5 张：正面/侧面/全身/背面）
├── scenes/       S 开头场景图（同一场景可多角度，统一风格前缀）
├── props/        P 开头道具图
├── refs/         R 开头风格参考/构图参考（非资产，仅风格锚点）
└── bible/        角色圣经（每角色一份 .md，文字版一致性锚点）
```

## 3. 角色圣经（Character Bible）——文字版一致性锚点

每角色一份 `bible/C01_林冲.md`，模板见 `prompts/character_bible.md`。内容包括：
外貌（发型/脸型/瞳色/体型）、服装（颜色/材质/配饰，给出十六进制色值）、道具绑定、声音（音色/语气）、表情与动作习惯、禁忌（绝对不能出现的特征，写成排除句）。

**用法**：生成每个镜头前，把角色圣经 + 定妆照一起作为输入（Ref2VA 参考图 + 圣经文本进提示词），保证跨镜头稳定。

## 4. 登记与校验（脚本自动化）

```bash
# 登记一个角色（会在 bible/ 生成模板、校验定妆照存在）
python3 scripts/asset_manager.py register C01 --name 林冲 --image assets/characters/C01_林冲_正面全身.png

# 列出全部资产
python3 scripts/asset_manager.py list

# 校验资产完整性（缺图/缺圣经会警告），生成素材清单
python3 scripts/asset_manager.py check
python3 scripts/asset_manager.py manifest --out output/S01_素材清单.md
```

## 5. 版本管理（推荐 git + LFS）

- `assets/` 和 `output/` 文件大，用 `git lfs` 或直接放网盘/对象存储同步
- 脚本、提示词模板、分镜脚本（文本）进普通 git
- 每集锁定：分镜脚本里记录「本镜用了 C 几的哪张图、S 几」——**素材清单就是可追溯性**（`asset_manager.py manifest` 生成）

## 6. 风格一致性铁律

所有资产生成提示词必须以**统一风格前缀**开头，例如：

```
Chinese ink wash painting style mixed with anime cel-shading, 9:16 vertical...
```

角色辨识度靠"颜色方案 + 视觉标记"区分（A 角色红披风、B 角色蓝发带……），写进角色圣经。
