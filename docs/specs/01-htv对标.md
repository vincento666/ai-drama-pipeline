# 01 · RHTV 对标（本地化 HTV）

> 状态：规划中 · 依据：2026-08 竞品调研（量子位 / CSDN 实测 / aidb 功能页）
> 一句话：**RHTV = RunningHub TV，原生 AI 智能体无限画布**（Agent + 画布 + RunningHub 生态）。

## 1. RHTV 是什么

- 定位：RunningHub 出品的「原生 AI 智能体全能创作平台」，浏览器即用、无需本地 GPU；
  底层 170+ 标准模型 API、10 万+ 社区应用、13681 节点（图/视频/音频/3D/文本五模态）。
- 入口：`rhtv.runninghub.ai/projects` 项目工作台：新建项目 → 唤醒 Agent → 自然语言指令。
- **三种生成模式**：常规图片 / 视频（手动建节点）/ **Agent 模式**（核心：对话式自动规划工作流）。
- **无限画布**：脚本、视觉资产、分镜、视频片段同屏铺开，拖拽节点 + 连线；Agent 画布原生内置。
- **每步可编辑、过程全透明、不抽卡**：任务拆解 → 创意大纲 → 确认参数 → 内容大纲/节拍表 →
  基准图 → 角色多视角 → 分镜 → 视频 → 剪辑，任一步可暂停/干预/局部修改；单分镜失败只调单镜，不整条重跑。
- 内置工具链：剪辑编辑器、摄影机控制、分镜大师（九/四/25 宫格）、宫格裁剪、打光、分层抠图、
  超清修复、帧提取、内容解析；公共素材库 +「导演台」3D/2D 分镜导演。
- 长期记忆（记住偏好/风格）；满意项目一键打包工作流整组复用。
- **模型内置、云端托管、不可自定义接入**（Seedance 2.0、可灵等）。

## 2. 剧本→分镜→参考图核心链路（RHTV 实测）

| # | 步骤 | 产出 | 人审点 |
|---|---|---|---|
| 1 | 输入想法 | Agent 任务拆解 + 3 种风格方向 | **选风格** |
| 2 | 剧情大纲 | 制作参数清单（时长/比例/画风，勾选确认） | **确认参数** |
| 3 | 角色资产设定 | 角色资产表（统一视觉特征） | 审核 |
| 4 | 角色参考图 | 三视图/多视角参考图（可文字迭代改造型） | **改造型** |
| 5 | 场景基准图 | 场景基准图（空白框预填生成第二张） | 审核 |
| 6 | 拆分分镜 | 镜头（特写/中景/远景/慢动作）+ 节拍表对照时间轴 | **调分镜** |
| 7 | 画布批量建节点 | 逐段调视频模型生成片段（可带 BGM） | 单镜局部重跑 |
| 8 | 内置剪辑器 | 裁剪/配乐/字幕 → 拼接成片，可无限续写 | **剪辑微调** |

## 4. 本地化原则（决策）

1. **每步落盘、可单独重跑**：任何一步的产物都是 `output/<项目>/` 下的文件，状态 = 文件存在与否；
   不做内存画布状态（可运行性 > 华丽度）。
2. **Agent 只做编排者**：LLM 负责拆解/大纲/分镜脚本/参考图提示词；图/视频经可插拔 provider
   （ComfyUI）产出——对齐「简单 agent + 本地生成」定位。
3. **一致性机制**：先锁角色/场景参考（Asset + bible + Shot ref），再生成分镜/视频——两家共同关键工序。
4. **UI 两阶段**：先 CLI/JSON 驱动 + 简单 Web 步骤面板（进度/产物预览/单步重跑），再演进无限画布；
   导出能力预留剪辑合成（字幕/配乐/拼接）接口。
5. **对比口径**：对标的是**流程能力**（可见性、可编辑性、局部重跑、参考图链路），不是云端算力。
6. **不重造 ComfyUI（战略边界）**：RHTV 生成层本质是 ComfyUI 工作流生态（RunningHub 官方
   ComfyUI_RH_* 插件为证）——我们的画布是**短剧领域专用操作面**（步骤/卡片/墙），通用节点画布一律
   复用 ComfyUI 原生 UI，图/视频生成一律走本地 ComfyUI API：**共用引擎，不复制引擎**。

## 5. Out of Scope

云端 GPU 与闭源模型、RunningHub 工作流市场与节点生态、多人在线协作、移动端。
