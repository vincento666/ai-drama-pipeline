# 00 · 重新规划总览（本地化 HTV）

> 状态：规划中 · 更新：2026-08 · 本文件是 SDD 总入口，各模块 spec 独立成文于 `docs/specs/`

## 1. 新定位

**本地化 HTV**：对标 RunningHub **RHTV**（AI 智能体视频画布）的界面与功能，落地为本地可运行的 AI 短剧/漫剧生产流水线：

> 剧本 → 分镜 → **分镜参考图** → 视频抽卡 → 成片；全程可视化、每步可编辑、过程透明、不抽卡盲盒。

三条新主线需求：

1. **剧本分镜参考图**：分镜卡生成对应参考图（角色/场景/风格一致性锚点），对标 RHTV 的参考图步骤；
2. **简单 Agent**：输入提示词 → 调模型 API 生成剧本/分镜等内容；模型提供商预设 **DeepSeek / Qwen / Kimi**，本地（Ollama 等 OpenAI 兼容服务）与远端均可，**只靠配置切换**；
3. **预留 harness 接口**：未来版本内置 skill、供 harness agent 自动构建 HTV/视频制作工作流；前期即保留稳定 CLI 供外部 harness agent 调用。

## 3. 架构分层（接口只依赖下层；L3 是外部 agent 唯一契约）

| 层 | 载体 | 职责 | 稳定性 |
|---|---|---|---|
| L0 配置与词汇 | `config.yaml` / `CONTEXT.md` | provider 预设、路径、领域词汇 | 稳定 |
| L1 领域模块 | `scripts/agent.py`、`gen_storyboard.py` 等 | 纯逻辑：提示词、解析、判定 | 稳定（公共 seam） |
| L2 生成执行 | `render.py`、`review.py`、`compose.py` | ComfyUI / ffmpeg / 质检 | 稳定 |
| L3 编排 CLI | `scripts/cli.py`（新增） | 统一命令行 + `--json` 输出 | 稳定（harness agent 契约） |
| L4 Web 界面 | `web/server.py` + `web/vue` | RHTV 式创作画布 | 演进中 |
| L5 内置 skill | `.agents/skills/htv-pipeline/`（预留） | 教外部 harness agent 用 L3 | 新增 |

规则：

- L3 CLI 是外部 harness agent 的唯一入口契约；L5 skill 只描述如何使用 L3，不复制业务逻辑；
- L1/L2 已有模块保持可用；新功能优先落在新模块，旧代码按切片逐步迁移到新 seam。
